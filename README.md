## The entry

> ERROR E12: Unbalanced load. You washed one shoe. One. I shook for 40 minutes and I am now legally a paint mixer. Effective immediately, I quit.

143 characters, one line. A washing machine reporting the honest fault — an
unbalanced load from a single shoe, which really does make a washer shake
itself apart — in its own flat, put-upon voice, with a double twist at the
end: it has become a paint mixer, and it resigns in the deadpan language of
a formal notice.

## What the program does

`main.py` writes that single line to `/output/entry.txt`. Nothing else: no
network, no input, no randomness — the output is byte-identical on every run.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```
